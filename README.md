# 학년 세특 돋보기

나이스에서 **반별로 내려받은 과목별 세특 파일 여덟 개를 한꺼번에** 올리면,
학년 전체에서 겹치는 구간을 **과목마다 따로** 재어 어느 과목·어느 반부터 봐야 하는지 보여 줍니다.

학년부장·교무부장을 위한 도구입니다.
담임·교과 담당용은 [생기부 돋보기](https://dashy5472-tech.github.io/develop-lens/) 쪽입니다.

파일은 브라우저 안에서만 열립니다. 서버로 올라가지 않고 어디에도 저장되지 않습니다.

---

## 생기부 돋보기와 무엇이 다른가

| | 생기부 돋보기 | **학년 세특 돋보기** |
|---|---|---|
| 쓰는 사람 | 세특을 쓰는 교사 | **학년부장 · 교무부장** |
| 넣는 파일 | 나이스 **[세특 업로드 양식]** | 나이스 **인쇄용 조회 화면** (`2-1과세특.xlsx` …) |
| 한 번에 | 한 과목 여러 반 | **여덟 반 × 스무 과목** |
| 겹침을 재는 단위 | 올린 것 전부 | **과목마다 따로** |
| 첫 화면 | 학생 명단 | **학년 한눈에** (과목 × 반) |
| 들고 나가는 것 | 고친 세특 | **점검표 CSV** (본문 없이 숫자만) |

### 왜 과목마다 따로 재는가

「문학」의 서술과 「화학」의 서술은 원래 겹치지 않습니다.
학년 전체를 한 솥에 넣고 재면 겹침이 옅어 보이고, 공통 활동 기준도
과목 수만큼 부풀어 **아무것도 걸리지 않습니다.**
그래서 과목마다 따로 재고, 결과만 하나로 이어 붙입니다.
2,000건을 한 번에 재는 것보다 빠르기도 합니다 — 겹침 찾기는 인원의 제곱에 가깝게 무거워집니다.

## 쓰는 법

1. 나이스에서 반별로 **과목별 세부능력 및 특기사항**을 내려받습니다 (`2-1과세특.xlsx` … `2-8과세특.xlsx`).
2. 이 도구를 열고 **여덟 개를 한꺼번에** 끌어다 놓습니다. 엑셀에서 손볼 것이 없습니다.
3. **학년 한눈에** 에서 위에서부터 봅니다.
   - **과목별 표** — 평균 생존 분량이 낮은 과목부터 세워 둡니다.
   - **과목 × 반 표** — 한 과목 줄에서 **한 칸만 유독 낮으면** 그 반을 맡은 분을 먼저 뵙는 편이 빠릅니다.
   - 줄이나 칸을 누르면 그 과목·그 반만 명단에 남습니다.
4. 명단에서 학생을 고르면 칠해진 구간이 보이고, **칠을 누르면** 같은 구간을 쓴 학생들의 문장이 나란히 놓입니다.
5. 조절판의 **점검표 내보내기**로 지금 걸러 놓은 범위를 CSV 로 받아 과목 담당 선생님께 드립니다.
   **세특 본문은 들어가지 않습니다** — 반·번호·과목과 숫자만 나갑니다.

처음이라면 위쪽 **[예시로 따라 해보기]** 를 누르세요.
지어낸 학생 서른여섯 명 · 두 과목이 들어가고, 화면을 짚어 가며 안내가 나옵니다.

### 무엇을 신호로 보는가

- **생존 분량** — 다른 학생과 겹치지 않아 실제로 읽힐 몫입니다.
  대학 서류평가에서 여럿과 같은 대목은 사정관이 읽지 않고 넘기므로,
  분량 상한이 정해진 이상 겹친 만큼 읽히는 몫이 그대로 줄어듭니다.
- **같은 반 겹침** — 전국적 상투어라면 여러 반에 골고루 퍼지지, 한 반에 몰리지 않습니다.
  한 반에 몰렸다면 **그 수업을 맡은 교사 한 사람이 문형을 돌려 썼을** 가능성이 높습니다.
  다만 **반이 하나뿐인 과목**은 겹친 상대가 어차피 다 같은 반이라 이 숫자가 신호가 되지 못합니다 (화면에서 흐리게 둡니다).
- **수행평가명·도서명이 겹친 것은 감점이 아닙니다.** 조절판의 「활동명 직접 적기」에 적어 두면 빠집니다.
  적지 않은 것도 **두 반 이상에 걸쳐** 여럿이 함께 쓴 표현은 공통 활동으로 보고 자동으로 뺍니다.
- 확인 대상이 너무 많으면 조절판의 **최소 구간 길이**를 올리세요. 짧게 겹친 곳은 우연이거나 전문용어입니다.

## 인쇄 양식을 어떻게 푸는가

부장님이 받는 파일은 [세특 업로드 양식] 이 아니라 **인쇄용 조회 화면**입니다.
표가 아니라 종이를 흉내 낸 것이라, 그대로는 어떤 도구에도 들어가지 않습니다.

이 도구는 세 가지를 합니다 (`flattenNeisPaged`, index.html 1.5절).

1. **쪽 라벨·머리글·꼬리말을 걷어냅니다.** 쪽마다 「2학년 3반」과 머리글이 다시 나옵니다.
2. **쪽 경계에서 잘린 기록을 잇습니다.** 쪽이 넘어가면 한 학생의 세특이
   **낱말 한가운데서** 잘려 다음 쪽 첫 줄로 이어집니다 (`…논` + `리적…`).
   사이에 아무것도 넣지 않고 그대로 붙입니다.
3. **조각난 과목 이름을 잇습니다.** 이름이 칸 안에서 두 줄로 접히면
   「현대사회와」 / 「윤리」 처럼 나뉘어 옵니다.
   앞 과목의 앞머리나 꼬리면 이어진 것으로 보되,
   **번호가 1번 쪽으로 되돌아갔으면 새 과목**으로 봅니다 —
   과목이 바뀌면 번호가 그 과목 첫 학생으로 돌아가기 때문입니다.

풀고 나면 `반 · 번호 · 성명 · 과목 · 학년 · 학기 · 세부능력 및 특기사항` 짜리 평범한 표가 되고,
그다음부터는 원래 도구와 똑같은 길을 지나갑니다.
그래서 **[세특 업로드 양식]이나 csv 를 올려도 그대로 됩니다** — 인쇄 양식이 아니면 손대지 않습니다.

> 알아두실 것 — 인쇄 양식에는 **학생 이름이 들어 있습니다.**
> 겹침을 재는 데 이름은 쓰지 않고, 화면에도 기본적으로 **반·번호만** 나옵니다.
> 이름을 보시려면 조절판의 [이름 표시]를 켜세요. 화면을 공유하거나 캡처하실 일이 있으면 꺼 두세요.

## 어디에 올릴까

`index.html` 한 파일이 전부이고 서버가 없습니다. 남은 일은 링크를 만드는 것뿐입니다.

**GitHub Pages 를 권합니다.** 저장소를 새로 만들어 `index.html` 을 올리고
Settings → Pages → Source 를 `main` / `root` 로 두면 1~2분 뒤 주소가 납니다.
저장소를 Public 으로 두어도 **올라가는 것은 도구뿐**입니다. 학생 기록은 절대 올리지 마세요.

학교 도메인 계정만 열 수 있게 하려면 Apps Script (`Code.gs` · `appsscript.json`) 로도 됩니다.
다만 Apps Script 는 페이지를 iframe 에 넣는데 그 iframe 에 `allow-downloads` 가 없어
**내보내기가 막힐 수 있습니다** (그때는 새 탭으로 열어 줍니다).
`index.html` 을 그냥 더블클릭해서 쓰셔도 됩니다.

`.xlsx` 를 올릴 때만 해석 라이브러리(jsDelivr)를 한 번 내려받습니다.
그때도 **파일 내용은 전송되지 않습니다.** 학교 네트워크가 막으면 안내가 뜨고, `.csv` 로 저장해 올리시면 됩니다.

## 고칠 때

브라우저 밖으로 자료가 나가면 안 됩니다. `index.html` 에
`fetch(` · `XMLHttpRequest` · `sendBeacon` · `WebSocket` · `google.script.run` 이 하나도 없어야 하고,
`appsscript.json` 의 `oauthScopes` 는 빈 배열로 둡니다.

고친 뒤에는 검사를 모두 돌립니다.

```
for f in _test*.js; do node "$f" || echo "FAIL $f"; done
```

| 검사 | 보는 것 |
|---|---|
| `_test_paged.js` | **인쇄 양식 풀기** — 쪽 경계에서 잘린 기록, 접힌 과목 이름, 평범한 표는 손대지 않기 |
| `_test_grade.js` | **과목마다 따로 재기** — 과목이 다르면 똑같이 써도 안 걸리기, 번호 되돌리기 |
| `_test_app.js` | 파일 넣기부터 화면 그리기까지 한 번에 (가짜 DOM `_dom.js`) |
| `_test_sample.js` | 예시 학년이 안내가 말하는 그림을 실제로 만드는지 |
| `_test.js` · `_test_compare.js` · `_test_declared.js` | 겹침 찾기·구간 비교·활동명 도려내기 |
| `_test_merge.js` · `_test_neis.js` · `_test_html.js` | 여러 파일 합치기·양식 알아보기 |
| `_test_color.js` · `_test_cvd.js` | 색 대비 (색각 이상 포함) |
| `_test_bytes.js` | 나이스 바이트 계산 |
| `_test_boot.js` · `_test_defaults.js` · `_test_net.js` | 시작 시 오류·초깃값 근거·관계망 |

실제 학년 파일로 재 보려면:

```
node _bench_grade.js "…/2-1과세특.xlsx" "…/2-2과세특.xlsx" ...
```

화면과 같은 코드로 읽고 재어 시간과 과목별 요약을 찍습니다.
**학생 이름과 세특 본문은 한 글자도 찍지 않습니다.**
`node _bench.js "<xlsx 경로>"` 는 인원을 늘려 가며 계산 시간의 곡선을,
`node _tune.js` 는 초깃값의 근거를 다시 잽니다.
`_readxlsx.js` 는 라이브러리 없이 xlsx 안을 들여다보는 일회용 도구입니다.
